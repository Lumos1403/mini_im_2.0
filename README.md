# mini_im_2.0

**mini_im_2.0** is an AI-native full-stack instant messaging system built with Go and Vue. The project explores how real-time communication, WebSocket messaging, JWT/Redis authentication, and an integrated personal AI agent can be combined into one practical application.

The long-term goal of this project is to become an open-source reference for **agent-augmented communication systems** and **AI-assisted software engineering workflows**.

## Key Features

* Full-stack IM architecture with Go, Gin, Vue, TypeScript, and WebSocket
* Real-time private and group messaging workflows
* JWT and Redis-based authentication design
* MySQL-based message, conversation, friend, and group data model
* Integrated personal AI agent for project-aware assistance
* Planned RAG support over local project documents
* Planned multi-route retrieval and reranking pipeline
* Planned local MCP-style tool integration for personal workflows
* Future Codex-driven multi-agent collaboration for development, testing, review, security, and documentation

## Why This Project Matters

Most IM demos focus only on message delivery. mini_im_2.0 focuses on a more AI-native direction: how a traditional communication system can be extended with an embedded personal agent, local knowledge retrieval, and safe tool execution.

This makes the project useful as a learning-oriented OSS reference for developers who want to understand both real-time application architecture and agent-based software development.

## Codex and Multi-Agent Development Plan

I plan to use Codex to improve this project through a multi-agent development workflow. Specialized agents will be responsible for architecture review, backend refactoring, frontend improvement, security auditing, automated testing, documentation, RAG optimization, retrieval/reranking evaluation, and MCP tool safety.

The goal is to use Codex not only as a coding assistant, but also as a maintainability and quality-improvement layer for the entire repository.
