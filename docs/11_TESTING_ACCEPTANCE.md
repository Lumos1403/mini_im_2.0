# 11 测试与验收标准

## 1. 测试原则

每完成一个模块都必须测试，不允许最后才整体测试。

测试范围：

```txt
接口测试
WebSocket 测试
数据库数据验证
前端交互测试
权限测试
异常测试
```

## 2. 用户认证验收

### 注册

必须满足：

```txt
可以使用 username + password + nickname 注册
username 重复时返回错误
密码不会明文存储
注册后生成 user_id
注册后创建 user_profiles
注册后创建默认 Agent 好友和会话
```

### 登录

必须满足：

```txt
正确账号密码可以登录
错误密码不能登录
返回 access_token 和 refresh_token
refresh_token 写入 Redis
access_token 可访问受保护接口
```

### 刷新和退出

```txt
Access Token 过期后可用 Refresh Token 刷新
退出登录后 Refresh Token 失效
```

## 3. 用户资料验收

```txt
可以获取当前用户资料
可以修改头像、性别、昵称、个性签名
nickname 可重复
不会返回 password_hash
```

## 4. 好友系统验收

### 搜索用户

```txt
可以按 user_id 精确搜索
可以按 nickname 模糊搜索
不展示已删除用户
```

### 好友申请

```txt
A 可以向 B 发起好友申请
B 可以看到申请
B 可以同意
B 可以拒绝
同意后双方好友列表出现对方
拒绝后不会成为好友
重复申请需要合理处理
```

### 删除好友

```txt
A 删除 B 后双方好友列表都移除
B 的聊天窗口出现系统提示：对方已将你删除
删除后允许重新申请好友
历史消息不被自动删除
```

### 拉黑

```txt
A 拉黑 B 后，B 发送消息显示红色感叹号
B 刷新后仍能在自己的历史消息中看到 failed_blocked
B 发送的消息不进入 A 的聊天记录
A 不收到任何推送
解除拉黑后，拉黑期间消息不补发
```

## 5. 会话系统验收

```txt
好友关系建立后存在单聊会话
会话列表显示最后一条消息
会话列表显示未读数
清空聊天记录只影响当前用户
清空后对方消息不受影响
```

## 6. WebSocket 验收

```txt
未登录不能连接 WebSocket
Token 无效不能连接 WebSocket
登录后可以连接
断开后在线状态清理
心跳正常
服务端可以推送消息
客户端发送消息后收到 ack
```

## 7. 单聊消息验收

```txt
A 给 B 发文字消息，B 在线时实时收到
B 离线时不会实时收到，但上线后可通过历史消息看到
发送成功后前端状态从 sending 变 sent
发送失败时显示失败状态
failed_blocked 刷新后仍保留在发送方历史中
聊天记录分页正常
```

## 8. 删除和清空验收

### 单条删除

```txt
A 删除某条消息后，A 界面立即消失
B 仍然可以看到该消息
A 搜索不到该消息
```

### 清空聊天记录

```txt
A 清空与 B 的聊天记录后，A 当前会话消息为空
B 不受影响
A 搜索不到清空前消息
新消息正常显示
```

## 9. 撤回验收

```txt
A 可以撤回自己 5 分钟内发送的消息
超过 5 分钟不能撤回
A 不能撤回 B 的消息
撤回后 A 和 B 的聊天窗口中原消息消失
B 不显示撤回提示
A 显示“你撤回了一条消息”提示
A 可以在 5 分钟内点击重新编辑
5 分钟后重新编辑内容失效
撤回消息不参与搜索
```

## 10. 文件验收

```txt
可以上传 50MB 内文件
超过限制返回错误
文件消息可以发送
会话成员可以下载文件
非会话成员不能下载文件
未登录不能下载文件
文件名可以搜索
被删除或清空前的文件消息不出现在搜索结果中
```

## 11. 群聊验收

```txt
用户可以创建群聊
创建者是群主
群号可以搜索
用户可以申请入群
群主或管理员可以审批入群
群成员可以发群消息
非群成员不能发群消息
被禁言成员不能发群消息
群主可以设置管理员
管理员不能设置管理员
群主和管理员可以禁言成员
群主可以解散群聊
群解散后不能继续发消息
群消息发送方只收到 ack，不收到自己的 receive
刷新后群历史消息分页可见，并包含 sender_nickname、sender_avatar_url、sender_group_role
```

### 群成员 GUI 和身份标识验收

```txt
群主发送群消息时，昵称旁显示金色“群主”
管理员发送群消息时，昵称旁显示绿色“管理员”
普通成员发送群消息时，不显示特殊身份标识
刷新页面后，历史群消息仍能显示正确身份标识
群成员列表可以展示头像、昵称、user_id、bio、role、mute_until、friendship_status
群成员列表中群主排在最前，管理员排在普通成员之前
点击群成员头像或昵称可以打开成员资料弹窗
点击自己时不显示添加好友按钮
点击非好友成员时可以发送好友申请
发送好友申请成功后按钮变为申请中
已是好友成员显示已是好友或发消息
群成员添加好友功能复用现有好友申请接口
```

## 12. 安全验收

```txt
接口无 Token 返回 401 或业务错误码
用户不能访问不属于自己的会话
用户不能删除别人的消息状态
用户不能伪造 sender_id
普通成员不能调用管理员接口成功
文件下载必须鉴权
日志中不出现明文密码和完整 Token
```

## 13. 高并发基础验收

MVP 阶段至少验证：

```txt
聊天记录分页加载
在线状态存在 Redis
Refresh Token 存在 Redis
WebSocket 连接断开能清理
发送消息接口不会一次性查询大量历史消息
关键表有索引
```

## 14. 推荐手工测试流程

```txt
1. 注册用户 A
2. 注册用户 B
3. A 登录，B 登录
4. A 搜索 B
5. A 申请好友
6. B 同意好友
7. A 给 B 发消息
8. B 实时收到
9. B 拉黑 A
10. A 再发消息，显示红色感叹号
11. B 解除拉黑
12. A 再发消息，B 正常收到
13. A 删除一条消息
14. B 确认仍可看到
15. A 撤回一条 5 分钟内消息
16. B 确认消息消失且无提示
17. A 上传文件并发送
18. B 下载文件
19. A 创建群聊
20. B 申请入群
21. A 审批通过
22. B 发送群消息
23. A 禁言 B
24. B 发送失败
```
